Connection and hosting help

Host this file over HTTPS. Chrome 142+ supports local HTTP connections after you allow local-network access in the site's permissions. Other browsers or managed browser policies may block them. Recheck permissions after a blocked scan, then scan again.

A browser cannot reliably determine your local subnet or enumerate every PC. Use the IPv4 range from your network settings. Only responding Overlay Timer APIs are found; repeat for other ranges or ports. A cloud server does not provide a route to your LAN.

OverlayTimer.exe must be running on each PC, with its timer port reachable through Windows Firewall. No manager service or port 18082 is used. If you see “Unreachable or blocked,” check the address, browser permissions, firewall, and HTTPS hosting.

For nginx, serve UI2.html as a static file. Any Content-Security-Policy must allow this file's inline scripts/styles and HTTP/HTTPS connections to your timers; do not apply upgrade-insecure-requests to this page.
